# تشغيل NuclearDecay Lab 2.1.0

## ابدأ دون تثبيت

1. فك ضغط ملف ZIP.
2. افتح مجلد `nuclear-decay-lab/dist`.
3. افتح `nuclear-decay-lab.html` في متصفح حديث.

التطبيق كامل داخل ملف واحد، ويعمل دون خادم أو حساب أو اتصال بالإنترنت. فتح روابط المراجع العلمية يحتاج اتصالًا بالإنترنت. بعض إعدادات المتصفح قد تقيّد الحفظ المحلي أو النسخ أو تنزيل الملفات؛ تظهر رسالة عند تعذر العملية.

اختر **العربية** من قائمة اللغة إذا أردت واجهة عربية. يظل ترتيب المعادلات والأرقام ووحدات SI من اليسار إلى اليمين. يمكن التبديل بين الوضع الفاتح والداكن.

## تحليل عينة

افتح **Complete Decay Analysis / التحليل الشامل للتحلل الإشعاعي**. اختر النظير وأدخل النشاط الابتدائي والزمن، ثم اضغط **Analyze Now / حلّل الآن**. للنظائر الثمانية الموثقة، تُستخدم القيم المرجعية تلقائيًا. ويمكن اختيار نصف عمر مخصص وإضافة اسم للنظير وكتلة مولية عند الحاجة فقط.

مثال موثق: اليود-131، نشاط ابتدائي `100 MBq`، وزمن `8.0233 d`. النتيجة `50 MBq` و`50%` متبقٍ. تغيير وحدة العرض يحوّل قيمة الإدخال ويحافظ على الكمية الفيزيائية نفسها.

اضغط **Show Calculation Steps / عرض خطوات الحل** لرؤية المعطيات، والتحويلات، والقانون، والتعويض والنتيجة الحالية. استخدم **Copy result / نسخ النتيجة** للنسخ، أو **Download report / تنزيل التقرير** لحفظ تقرير HTML.

## ميزات الإصدار الثاني

- **الحاسبة العكسية:** اختر المتغير المجهول؛ تظهر المعطيات الضرورية فقط. مثال نصف العمر: نشاط ابتدائي `100 MBq`، ونهائي `25 MBq`، وزمن `16 d` يعطي نصف عمر `8 d`. تساوي النشاطين أو الزمن الصفري لا يحددان نصف عمر مشع محدودًا بصورة وحيدة.
- **التحليل الزمني:** أدخل أزمنة محددة أو بداية ونهاية وعدد نقاط من 2 إلى 1000. اختر النشاط أو النسبة المتبقية أو الأنوية أو الكتلة أو انخفاض النشاط. الجدول والرسم يستخدمان النقاط الحسابية نفسها.
- **مقارنة النظائر:** اختر 2 إلى 8 نظائر، ونشاطًا ابتدائيًا موحدًا أو قيمًا مختلفة. يمكن إخفاء المنحنيات، وتكبير المجال، وتحديد زمن للفحص، واستخدام المقياس اللوغاريتمي.
- **مكتبة النظائر:** ابحث بالاسم أو الرمز أو العدد الذري، واطّلع على عدم اليقين والمصدر، ثم افتح النظير في التحليل.
- **تعلّم التحلل النووي:** دروس قصيرة وتجربة تفاعلية تربط أنصاف الأعمار بالنشاط المتبقي.

## حفظ التحليل ومشاركته

**حفظ التحليل** يحفظ آخر مجموعة مدخلات لكل حاسبة في المتصفح. **فتح آخر تحليل** يسترجعها. **مسح المدخلات** يمسح النموذج، و**مسح جميع البيانات** يمسح بيانات التطبيق وتفضيلاته فقط، دون بيانات التطبيقات الأخرى.

رابط المشاركة يحتوي المدخلات بترميز قابل للقراءة، وليس بتشفير؛ استخدمه للبيانات غير الحساسة. المشاركة بين أجهزة مختلفة تحتاج رابط نسخة منشورة، مثل GitHub Pages. الرابط الناتج من ملف `file://` محلي لا ينقل ملف التطبيق إلى جهاز آخر.

## التقارير والتنزيل

يمكن تنزيل الجداول بصيغة CSV بدقة عددية كاملة، والرسم الحالي بصيغة PNG، والتقرير بصيغة HTML. اضغط **Print / PDF / طباعة / PDF** واختر **Save as PDF** في نافذة طباعة المتصفح لحفظ PDF بتنسيق A4. يمكن أيضًا فتح تقرير HTML المحفوظ وطباعته لاحقًا.

في المقارنة، تصدير CSV العادي يحفظ جدول الزمن المختار. **Export curves CSV** يحفظ 181 نقطة لجميع النظائر المختارة على المجال المحدد بالمدخلات؛ إخفاء منحنى أو تكبير العرض لا يحذفه من تصدير البيانات.

## تشغيل نسخة التطوير

ثبّت Node.js بإصدار `22.12` أو أحدث، وافتح الطرفية داخل مجلد المشروع:

```bash
npm ci
npm run dev
```

افتح العنوان الذي يعرضه Vite. للتحقق والبناء:

```bash
npm test
npm run typecheck
npm run build
npm run verify:build
```

`verify:build` يشغّل النسخة المجمعة داخل محاكي DOM؛ لا يعادل فحصًا بصريًا بمتصفح حقيقي.

## تحديث نفس مستودع GitHub

اتبع [تعليمات تحديث المستودع الحالي](UPDATE_GITHUB_AR.md). لم تُنشر هذه النسخة على الموقع الحي. للإنشاء العام على GitHub Pages:

1. أنشئ مستودعًا على GitHub.
2. ارفع محتويات `nuclear-decay-lab`، بما فيها `.github` و`package-lock.json`، مع استبعاد `node_modules` و`coverage`.
3. اجعل الفرع الرئيسي اسمه `main`.
4. من **Settings → Pages → Source** اختر **GitHub Actions**.
5. سير العمل المرفق يثبت الاعتماديات ويشغّل الاختبارات وفحص TypeScript والبناء وفحص النسخة الإنتاجية، ثم ينشر `dist`.

الإعداد الافتراضي `base: './'` يعمل داخل مسار المستودع، والتنقل باستخدام `#/` يمنع أخطاء إعادة تحميل الصفحات. لم يُنشأ مستودع عام ولم يُنشر المشروع على حسابك أثناء إعداد هذا الإصدار.

## حدود الحساب والتحقق

النموذج يخص نظيرًا أبًا منفردًا، ولا يحسب نمو البنات أو السلاسل أو الجرعة أو التدريع. تُعرض مساهمة نصف العمر المرجعي وحدها لتوجيه تقريب النتائج دون استنتاج عدم يقين كلي أو افتراض أخطاء لمدخلات المستخدم. الهدف الصفري من نشاط ابتدائي موجب لا يُبلغ في زمن محدود، والصفر الناتج عن حدود الدقة العددية موضح برسالة.

نتائج الاختبارات والمراجعة موجودة في `docs/verification.md` و`docs/SCIENTIFIC_AUDIT_REPORT.md` و`docs/SCIENTIFIC_VALIDATION.md`. لم تتوفر أداة المتصفح المطلوبة للفحص البصري الحقيقي؛ لذلك لا يُدّعى التحقق من جودة العرض على أجهزة فعلية أو من الصورة الناتجة عن تحويل SVG إلى PNG أو من نافذة الطباعة الفعلية.

## Carbon-14 ودقة العرض

نصف العمر المختار من DDEP هو `5700 ± 30 a`. السنة المرجعية `31556926 s`، وسنة الواجهة اليوليانية `31557600 s`. لذلك يحتفظ التطبيق بقيمة `5699.878260704236 y` مع عرض مختصر `5700`؛ انقر داخل الحقل لترى القيمة الكاملة أو تحررها. التنسيق لا يغير القيمة المحفوظة.

للنشاط الابتدائي `100 MBq` والزمن المدخل صراحة `5730 y`، تعرض النتيجة المعتادة `49.82 MBq`، والقيمة العددية المركزية `49.817183766240387… MBq` محفوظة في التفاصيل وCSV. عند زمن يساوي نصف العمر المختار تمامًا تكون النتيجة `50 MBq`. لا يغيّر التطبيق بيانات المصدر لإجبار نتيجة أخرى.

تفاصيل الحساب لا تعني دقة قياس إضافية، ومساهمة نصف العمر ليست فاصل ثقة أو ميزانية عدم يقين كاملة. يحتوي الإصدار على 309 اختبارات ناجحة؛ توثيق الفحوص وحدودها داخل مجلد docs.
